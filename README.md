# txtReader

一款纯前端、可安装的 TXT 文本阅读器。无需后端服务，导入的文件、阅读进度和设置均保存在浏览器本地。

## 功能特性

- 导入 TXT 及 gzip 压缩文本，支持 UTF-8、GBK、Big5、UTF-16 等编码。
- 翻页与滚动两种阅读模式，默认使用滚动模式。
- 自定义字体、字号、行高、段落间距及深浅色主题。
- 导入后默认使用 `第*章` 规则生成目录，也可通过通配符或正则表达式自定义目录模板。
- 支持书签、全文搜索、阅读进度跳转和语音朗读。
- 滚动模式支持自动滚动及速度调节。
- 支持 PWA 安装、离线使用及系统文件分享导入。

## 本地运行

项目使用原生 HTML、CSS 和 JavaScript ES Modules，无需安装依赖或执行构建。

在项目根目录启动静态服务器：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000/
```

请通过 HTTP 服务访问，不要直接使用 `file://` 打开，否则 ES Modules、数据加载和 Service Worker 无法正常工作。

## 基本使用

1. 点击文件列表左上角的“添加”按钮，或将一个文本文件拖入列表。
2. 点击导入的文件开始阅读。
3. 在阅读界面打开目录、书签或搜索面板。
4. 点击文件列表右上角的“设置”按钮，调整阅读模式、主题、字体和文本预处理等选项。

新导入的文件会自动按 `第*章` 模板解析目录。如果章节标题不符合该规则，可在目录面板点击“刷新目录”，输入新的模板重新生成。

目录模板支持：

- `*`：匹配任意内容。
- 半角空格：匹配任意空白字符。
- `/表达式/标志`：使用正则表达式匹配。

文本预处理仅在导入时执行，修改预处理设置不会影响已导入的文件。

## 数据存储

文件正文、目录、书签、阅读进度和设置使用 IndexedDB 保存在当前浏览器配置中。

清除网站数据、浏览器存储空间不足或更换浏览器可能导致数据丢失。**请勿将 txtReader 作为文本文件的存储或备份工具。**

## 项目结构

```text
index.html              页面容器与 HTML 模板
js/main.js              应用入口
js/page/                文件列表、阅读与设置页面
js/data/                配置及 IndexedDB 持久化
js/text/                文本解码、预处理、目录与朗读
js/ui/                  通用界面组件和工具
css/                    页面、主题及图标样式
data/                   简繁转换数据
help/                   使用帮助与第三方许可说明
manifest.webmanifest    PWA 配置
sw.js                   离线缓存与分享导入
```

## PWA 缓存维护

`sw.js` 通过显式 `resourceList` 管理离线资源，没有自动生成缓存清单的构建步骤：

- 新增、删除或重命名离线资源时，同步更新 `resourceList`。
- 发布缓存内容变化时更新 `version`，以生成新的缓存键并清理旧缓存。
- 本地调试遇到旧资源时，可在浏览器开发者工具中注销 Service Worker、清除 Cache Storage 后重新加载。
